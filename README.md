# Chaos Mod — 60 Событий и Квесты (Forge 1.20.1, Multiplayer Ready)

Полноценный мод для **Minecraft Forge 1.20.1** с поддержкой одиночной игры и мультиплеера.

## Что реализовано в моде

1. **60 уникальных событий (Каждую минуту):**
   - **Категория 1: Насилие над клиентом, камерой и интерфейсом** (12 событий: *DVD-скринсейвер*, *Австралийский гейминг*, *Капча на выживание*, *Фальшивый краш*, *Шизофазия звука*, *Нарциссизм*, *Роскомнадзор*, *Фантомная боль*, *Близорукость деда*, *Снайперский прицел*, *Слепая зона*, *Дискотека 80-х*).
   - **Категория 2: Инвалидность управления и физики** (12 событий: *Пьяный мастер*, *Коровий лед*, *Отказали тормоза*, *Клаустрофобия*, *Лилипут*, *Гравитация Юпитера*, *Симулятор Ростелекома*, *Пол — это кактус*, *Акрофобия*, *Дырявые руки*, *Пружина*, *Отдача 100-го уровня*).
   - **Категория 3: Социальная инженерия и бунт мобов** (12 событий: *Восстание веганов*, *Плачущий ангел*, *Крипер-пранкер*, *Рокировка*, *Куриный бомбардировщик*, *Судебный пристав*, *Обратная психология*, *Зомби-таджики*, *Черная дыра*, *Скелеты-космонавты*, *Маскировка*, *Хор осуждения*).
   - **Категория 4: Экономический кризис и блоки** (12 событий: *Наперсточник*, *Горячая картошка*, *Гравийное проклятие*, *Мидас из трущоб*, *Санкции*, *Бунт мебели*, *Стеклянный мир*, *Просрочка*, *Рандомайзер крафта*, *Нефтяной разлив*, *Минное поле*, *Налог на воздух*).
   - **Категория 5: Подачки судьбы** (12 событий: *Бессмертие в кредит*, *Алмазный дождь с Алиэкспресс*, *Лазерный взгляд*, *Гуманитарная помощь*, *Человек-бур*, *ЧВК «Голем»*, *Кузнец в кармане*, *Крио-шаг*, *Легальный X-Ray*, *Пылесос*, *Второе дыхание*, *Креативный полет (Демо-версия)*).

2. **Система квестов (Каждые 5 минут), Наград и Наказаний:**
   - **12 квестов** с прогресс-баром и таймером сверху экрана (*«Потрогай траву»*, *«Жертва богам рандома»*, *«Агрессивный зритель»*, *«Прыжок веры»*, *«Диоген»*, *«Дегустатор»*, *«Экстремальный альпинизм / Спелеология»*, *«Пацифист под прессингом»*, *«Водные процедуры»*, *«Дизайнер интерьера»*, *«Снайпер»*, *«Пироман»*).
   - **5 наград за выполнение** (*Королевская казна*, *Дар бессмертия*, *Благословение героя*, *Подгон кузнеца*, *Подарок судьбы*).
   - **5 наказаний за провал** (*Конфискация имущества*, *Карцер*, *Космическая программа*, *Хроническая усталость*, *Карательный отряд*).

3. **Меню настроек на клавишу `I` (в стиле Minecraft):**
   - Тумблер режима: **Вкл / Пауза таймеров / Выкл**.
   - Ползунки времени: интервал событий (10–300 сек), интервал квестов (60–900 сек), время на выполнение квеста (30–300 сек).
   - Настройка позиции HUD (переключение по углам или **перетаскивание мышкой прямо на экране**) + тумблер звукового тиканья на последних 5 секундах.
   - Менеджер всех 60 событий: фильтрация по категориям, галочки Вкл/Выкл (чёрный список), кнопка **«▶ Запустить сейчас»** напротив каждого события и панель инспектора активных событий.

## Как собрать мод через GitHub Actions

1. Загрузите все файлы из этой папки в ваш GitHub-репозиторий.
2. Перейдите во вкладку **Actions** в репозитории GitHub.
3. Workflow `Build Forge 1.20.1 Mod` (`.github/workflows/build.yml`) автоматически запустится при пуше (также его можно запустить вручную кнопкой **Run workflow**).
4. После завершения сборки скачайте готовый архив `chaosmod-forge-1.20.1` в разделе **Artifacts** — внутри будет готовый `.jar` файл мода для папки `mods`.
